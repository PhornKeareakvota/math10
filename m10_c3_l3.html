ជំពូកទី៣ មេរៀនទី៤៖ វិសមីការនិងប្រព័ន្ធវិសមីការ

គណិតវិទ្យាកម្រិតថ្នាក់ទី១០

រៀបចំដោយលោកគ្រូ ផន គារវតា

ខ្លឹមសារមេរៀន

សញ្ញាណដំបូងនិងរបកគំហើញវិសមីការនិងប្រព័ន្ធវិសមីការ

ប្រវត្តិ និងរបកគំហើញ៖ តាំងពីសម័យបុរាណ ក្នុងជីវភាពរស់នៅប្រចាំថ្ងៃ ដូចជាការជួញដូរ ការវាស់វែងដីធ្លី ឬការសាងសង់ មនុស្សមិនត្រឹមតែជួបប្រទះនូវបរិមាណដែល "ស្មើគ្នា" ប៉ុណ្ណោះទេ តែជារឿយៗតែងតែជួបនូវបរិមាណដែល "ច្រើនជាង" "តិចជាង" "យ៉ាងហោចណាស់" ឬ "យ៉ាងច្រើនបំផុត"។

  • និមិត្តសញ្ញា \(>\) (ធំជាង) និង \(<\) (តូចជាង) ត្រូវបានណែនាំដំបូងដោយគណិតវិទូជនជាតិអង់គ្លេសឈ្មោះ Thomas Harriot នៅក្នុងឆ្នាំ ១៦៣១។
  • ក្រោយមក និមិត្តសញ្ញា \(\ge\) (ធំជាងឬស្មើ) និង \(\le\) (តូចជាងឬស្មើ) ត្រូវបានបង្កើតនិងប្រើប្រាស់យ៉ាងទូលំទូលាយដើម្បីសម្រួលដល់ការសរសេរលក្ខខណ្ឌដែនកំណត់ (Boundary Conditions)។

សារៈសំខាន់នៃការសិក្សា៖

នៅក្នុងពិភពពិត ធនធាន (ពេលវេលា, ថវិកា, វត្ថុធាតុដើម) តែងតែមានដែនកំណត់। វិសមីការ និងប្រព័ន្ធវិសមីការ មានតួនាទីយ៉ាងសំខាន់ជួយយើងក្នុងការកំណត់រក តម្លៃអតិបរមា (Maximum) ឬ តម្លៃអប្បបរមា (Minimum) សម្រាប់ការរៀបចំផែនការ ការបែងចែកធនធាន និងការសម្រេចចិត្តក្នុងវិស័យសេដ្ឋកិច្ច ពាណិជ្ជកម្ម និងវិស្វកម្មជាដើម។

១. វិសមភាព

និយមន័យ៖ វិសមភាព គឺជាទំនាក់ទំនងរវាងកន្សោមពីរដោយប្រើសញ្ញា \(>\), \(<\), \(\ge\), ឬ \(\le\)

រូបមន្តលក្ខណៈ៖ បើ \(a < b\)

  • បូក/ដក៖ \(a + c < b + c\)
  • គុណ/ចែក (វិជ្ជមាន)៖ បើ \(c > 0 \Rightarrow ac < bc\)
  • គុណ/ចែក (អវិជ្ជមាន)៖ បើ \(c < 0 \Rightarrow ac > bc\) (ប្តូរទិសដៅសញ្ញា)

លំហាត់គំរូ៖

ប្រៀបធៀប \(-3x\) និង \(-3y\) ដោយដឹងថា \(x < y\)

ដំណោះស្រាយ៖ ដោយសារ \(x < y\) គុណអង្គទាំងពីរនឹង \(-3\) (ចំនួនអវិជ្ជមាន ត្រូវប្តូរសញ្ញា) នាំឲ្យ \(-3x > -3y\)

២. វិសមីការដឺក្រេទី១មានមួយអញ្ញាត

ទម្រង់ទូទៅ៖ \(ax + b > 0\) (ឬ \(<, \ge, \le\)) ដែល \(a \ne 0\)

សិក្សាសញ្ញាទ្វេធាដឺក្រេទី១ \(f(x) = ax + b\)

ដើម្បីសិក្សាសញ្ញាទ្វេធា \(ax + b\) យើងត្រូវ៖

  • រកឫសនៃទ្វេធា៖ ឲ្យ \(ax + b = 0 \Rightarrow x = -\frac{b}{a}\)
  • ប្រើវិធានសញ្ញា៖ "ខាងឆ្វេងឫស មានសញ្ញាផ្ទុយពី \(a\), ខាងស្ដាំឫស មានសញ្ញាដូច \(a\)"
\(x\) \(-\infty\) \(-\frac{b}{a}\) \(+\infty\)
\(ax + b\) សញ្ញាផ្ទុយ \(a\) \(0\) សញ្ញាដូច \(a\)

លំហាត់គំរូ (ដោយប្រើតារាងសញ្ញា)៖

ដោះស្រាយវិសមីការ៖ \(3x - 6 < 0\)

ដំណោះស្រាយ៖

  • រកឫស៖ ឲ្យ \(3x - 6 = 0 \Rightarrow 3x = 6 \Rightarrow x = 2\)
  • មេគុណ \(a = 3 > 0\) (មានសញ្ញាបូក \(+\))
\(x\) \(-\infty\) \(2\) \(+\infty\)
\(3x - 6\) \(-\) \(0\) \(+\)

ដោយសារវិសមីការយកលក្ខខណ្ឌ \(< 0\) (អវិជ្ជមាន), យើងមើលក្នុងតារាងកន្លែងដែលមានសញ្ញាដក (\(-\))។

ដូចនេះ សំណុំចម្លើយគឺ៖ \(x \in (-\infty, 2)\)

លំហាត់គំរូ (ដោយប្រើការបោះអង្គ)៖

ដោះស្រាយវិសមីការ៖ \(-2x + 8 \ge 0\)

ដំណោះស្រាយ៖ \(-2x \ge -8 \Rightarrow x \le \frac{-8}{-2} \Rightarrow x \le 4\). សំណុំចម្លើយ \(x \in (-\infty, 4]\)

លំហាត់អនុវត្តបែបដូរលេខ៖

ដោះស្រាយវិសមីការ៖ \(\dots\)

៣. ប្រព័ន្ធវិសមីការដឺក្រេទី១មានមួយអញ្ញាត

ជាប្រព័ន្ធដែលមានវិសមីការដឺក្រេទី១ច្រើន។ ចម្លើយគឺជាប្រសព្វ (Intersection) នៃសំណុំចម្លើយនីមួយៗ។

លំហាត់គំរូ៖

ដោះស្រាយប្រព័ន្ធ៖ \( \begin{cases} x - 2 \le 3 \\ -x + 1 < -2 \end{cases} \)

ដំណោះស្រាយ៖
(1): \(x \le 5\)
(2): \(-x < -3 \Rightarrow x > 3\)
សំណុំចម្លើយរួម៖ យកប្រសព្វនៃអ័ក្សចំនួន គឺ \(3 < x \le 5\)

៤. វិសមីការដឺក្រេទី២មានមួយអញ្ញាត

ទម្រង់៖ \(ax^2 + bx + c > 0\) (ឬ \(<, \ge, \le\)) ដែល \(a \ne 0\)

សិក្សាសញ្ញាត្រីធាដឺក្រេទី២ \(f(x) = ax^2 + bx + c\)

គណនាឌីស្គ្រីមីណង់ \(\Delta = b^2 - 4ac\) រួចពិនិត្យតាមករណីទាំង៣៖

ករណីទី១៖ \(\Delta > 0\) (មានឫសពីរផ្សេងគ្នា \(x_1 < x_2\))

វិធាន៖ "ចន្លោះឫសសញ្ញាផ្ទុយ \(a\), ក្រៅឫសសញ្ញាដូច \(a\)"

\(x\) \(-\infty\) \(x_1\) \(x_2\) \(+\infty\)
\(f(x)\) សញ្ញាដូច \(a\) \(0\) សញ្ញាផ្ទុយ \(a\) \(0\) សញ្ញាដូច \(a\)

ករណីទី២៖ \(\Delta = 0\) (មានឫសឌុប \(x_0 = -b/2a\))

\(x\) \(-\infty\) \(x_0\) \(+\infty\)
\(f(x)\) សញ្ញាដូច \(a\) \(0\) សញ្ញាដូច \(a\)

ករណីទី៣៖ \(\Delta < 0\) (គ្មានឫសក្នុង \(\mathbb{R}\))

\(x\) \(-\infty\) \(+\infty\)
\(f(x)\) មានសញ្ញាដូច \(a\) ជានិច្ច គ្រប់ \(x \in \mathbb{R}\)

លំហាត់គំរូ៖

ដោះស្រាយវិសមីការ៖ \(x^2 - 4x + 3 < 0\)

ដំណោះស្រាយ៖

  • រកឫសនៃ \(x^2-4x+3=0\) គឺ \(x_1=1, x_2=3\) (\(\Delta > 0\))
  • មេគុណ \(a=1 > 0\) (មានសញ្ញាបូក \(+\))
\(x\) \(-\infty\) \(1\) \(3\) \(+\infty\)
\(f(x)\) \(+\) \(0\) \(-\) \(0\) \(+\)

ដូចនេះ សំណុំចម្លើយគឺ៖ \(x \in (1, 3)\)

៥. ការអនុវត្តន៍វិសមីការ

លំហាត់ចំណោទគំរូ៖

ពិន្ទុគណិតវិទ្យា ២ខែដំបូងរបស់ដារ៉ាគឺ ៧៥ និង ៨០។ តើខែទី៣ គាត់ត្រូវទទួលបានពិន្ទុយ៉ាងតិចប៉ុន្មាន ទើបមធ្យមភាគយ៉ាងតិច ៨០?

ដំណោះស្រាយ៖ តាង \(x\) ជាពិន្ទុខែទី៣។
\(\frac{75 + 80 + x}{3} \ge 80 \Rightarrow 155 + x \ge 240 \Rightarrow x \ge 85\)

៦. ការបង្ហាញវិសមភាព

គោលការណ៍គ្រឹះដ៏សំខាន់បំផុតក្នុងការបង្ហាញវិសមភាពគឺ៖ ការេនៃគ្រប់ចំនួនពិត ជានិច្ចកាលធំជាង ឬស្មើ ០ (\(X^2 \ge 0\))

លំហាត់គំរូមូលដ្ឋាន៖

បង្ហាញថា បើ \(x > 0\) នោះ \(x + \frac{1}{x} \ge 2\)

ដំណោះស្រាយ៖ យើងដឹងថា \(\left(\sqrt{x} - \frac{1}{\sqrt{x}}\right)^2 \ge 0\)

\(\Rightarrow (\sqrt{x})^2 - 2(\sqrt{x})\left(\frac{1}{\sqrt{x}}\right) + \left(\frac{1}{\sqrt{x}}\right)^2 \ge 0\)

\(\Rightarrow x - 2 + \frac{1}{x} \ge 0 \Rightarrow x + \frac{1}{x} \ge 2\) (ពិត)

លំហាត់វិសមភាពគួរឲ្យចាប់អារម្មណ៍ (លំហាត់សិស្សពូកែ)

បង្ហាញថា ចំពោះគ្រប់ចំនួនពិត \(a, b\) និង \(c\) គេបាន៖
\(a^2 + b^2 + c^2 \ge ab + bc + ca\)

គន្លឹះដោះស្រាយ៖

ដើម្បីដោះស្រាយលំហាត់នេះ យើងត្រូវប្រើល្បិច "គុណនឹង ២" ដើម្បីបង្កើតជាទម្រង់រូបមន្តការេនៃទ្វេធា \((x-y)^2 = x^2 - 2xy + y^2\)

បកស្រាយលម្អិត៖

  • ១. គុណអង្គសងខាងនៃវិសមភាពនឹង ២៖
    \(2a^2 + 2b^2 + 2c^2 \ge 2ab + 2bc + 2ca\)
  • ២. បោះតួទាំងអស់ទៅអង្គទី១៖
    \(2a^2 + 2b^2 + 2c^2 - 2ab - 2bc - 2ca \ge 0\)
  • ៣. បំបែក និងផ្ដុំតួជា ៣ ក្រុម៖
    \((a^2 - 2ab + b^2) + (b^2 - 2bc + c^2) + (c^2 - 2ca + a^2) \ge 0\)
  • ៤. ប្រើរូបមន្តការេនៃទ្វេធា៖
    \((a-b)^2 + (b-c)^2 + (c-a)^2 \ge 0\)

សន្និដ្ឋាន៖ ដោយសារការេនៃចំនួនពិតជានិច្ចកាល \(\ge 0\) នោះផលបូករបស់វាក៏ \(\ge 0\) ដែរ។ ដូចនេះវិសមភាពត្រូវបានបង្ហាញ!

៧. មធ្យមនព្វន្ត មធ្យមធរណីមាត្រ (AM-GM)

ចំពោះចំនួនពិតវិជ្ជមាន \(a, b > 0\), គេបាន \(\frac{a+b}{2} \ge \sqrt{ab}\) ឬ \(a+b \ge 2\sqrt{ab}\)

លំហាត់វិសមភាព AM-GM គួរឲ្យចាប់អារម្មណ៍

បង្ហាញថា ចំពោះគ្រប់ចំនួនពិតវិជ្ជមាន \(a, b, c > 0\) គេបាន៖
\((a+b)(b+c)(c+a) \ge 8abc\)

គន្លឹះដោះស្រាយ៖

យើងត្រូវអនុវត្តវិសមភាព AM-GM ទៅលើកត្តានីមួយៗនៃអង្គទី១ រួចធ្វើផលគុណបញ្ចូលគ្នា។

បកស្រាយលម្អិតមួយជំហានម្តងៗ៖

  • ១. អនុវត្ត AM-GM លើ \(a\) និង \(b\):
    \(a+b \ge 2\sqrt{ab}\)    (1)
  • ២. អនុវត្ត AM-GM លើ \(b\) និង \(c\):
    \(b+c \ge 2\sqrt{bc}\)    (2)
  • ៣. អនុវត្ត AM-GM លើ \(c\) និង \(a\):
    \(c+a \ge 2\sqrt{ca}\)    (3)
  • ៤. ដោយសារអង្គសងខាងសុទ្ធតែវិជ្ជមាន យើងអាចគុណវិសមភាព (1), (2), (3) បញ្ចូលគ្នា:
    \((a+b)(b+c)(c+a) \ge (2\sqrt{ab})(2\sqrt{bc})(2\sqrt{ca})\)
  • ៥. សម្រួលអង្គទី២:
    \(= 8\sqrt{a^2b^2c^2}\)
    \(= 8abc\)

សន្និដ្ឋាន៖ វិសមភាព \((a+b)(b+c)(c+a) \ge 8abc\) ពិតជាត្រឹមត្រូវ!
(សញ្ញាស្មើកើតឡើងលុះត្រាតែ \(a=b=c\))

លំហាត់អនុវត្តបែបដូរលេខ (AM-GM)：

រកតម្លៃអប្បបរមានៃ \(f(x) = x + \frac{16}{x}\) (\(x>0\))

៨. ការអនុវត្តន៍ក្នុងជីវភាព (PISA តេស្ត)

តេស្ត PISA ផ្តោតលើសមត្ថភាពសិស្សក្នុងការយកចំណេះដឹងទៅដោះស្រាយបញ្ហាពិតក្នុងសង្គមជាក់ស្តែង។ ខាងក្រោមនេះគឺជាលំហាត់អនុវត្តវិសមីការតាមវិស័យនីមួយៗ៖

លំហាត់កសិកម្ម (ការស្វែងរកផ្ទៃអតិបរមា)

កសិករម្នាក់មានរបងលួសប្រវែង \(60m\) ដើម្បីព័ទ្ធដីកសិដ្ឋានរាងចតុកោណកែងដោយជាប់នឹងជញ្ជាំងផ្ទះមួយចំហៀង (មិនបាច់ព័ទ្ធលួស)។ តើគាត់ត្រូវកំណត់ទទឹងប៉ុន្មានម៉ែត្រ ទើបផ្ទៃដីដាំដុះបានអតិបរមា?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 3D៖

  • តាង \(x\) ជាទទឹងនៃរបង (\(x > 0\)), នោះបណ្ដោយគឺ \(y\)។
  • ប្រវែងរបងសរុបមានតែ ៣ជ្រុង៖ \(2x + y = 60 \Rightarrow y = 60 - 2x\)
  • ផ្ទៃដី (ពណ៌បៃតងក្នុង 3D)៖ \(S = xy = x(60 - 2x)\)
  • របងលួសពណ៌ខៀវក្នុង 3D៖ តំណាងឲ្យជ្រុងទាំង៣ ដែលមានប្រវែងសរុបថេរ ៦០ម៉ែត្រ។
អនុវត្តវិសមភាព AM-GM លើ \(2x\) និង \(60-2x\)៖

\(2x(60-2x) \le \left(\frac{2x + 60 - 2x}{2}\right)^2\)

\(2S \le \left(\frac{60}{2}\right)^2 \Rightarrow 2S \le 900 \Rightarrow S \le 450\)

អតិបរមាកើតឡើងពេល \(2x = 60-2x \Rightarrow 4x = 60 \Rightarrow x = 15m\)

សន្និដ្ឋាន៖ ទទឹង ១៥ម, បណ្ដោយ ៣០ម, ផ្ទៃអតិបរមា ៤៥០ម²

អូសបង្វិល (4D Animate)

បម្រែបម្រួលផ្ទៃដីតាមទំហំទទឹង និងបណ្ដោយ

លំហាត់ពាណិជ្ជកម្ម (ការវិភាគប្រាក់ចំណេញ)

ក្រុមហ៊ុនមួយចង់រកចំណេញឱ្យបាន យ៉ាងតិច \(5000\$\) ក្នុងមួយខែ។ បើចំណាយថេរប្រចាំខែ (ថ្លៃជួលកន្លែង ទឹកភ្លើង...) គឺ \(2000\$\) ហើយប្រាក់ចំណេញសុទ្ធលើការលក់ផលិតផលមួយគឺ \(10\$\)។ តើត្រូវលក់ផលិតផលយ៉ាងតិចប៉ុន្មាន?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយក្រាហ្វ 4D ខាងស្តាំ៖

  • តាង \(x\) ជាចំនួនផលិតផលដែលត្រូវលក់ (\(x > 0\))
  • ប្រាក់ចំណេញសរុបពីការលក់ = \(10x - 2000\)
  • របារក្រហម៖ លក់បាន ៤០០ ផលិតផល ចំណេញទើបបាន ២០០០$ (មិនទាន់ដល់គោលដៅ)
  • របារលឿង៖ លក់បាន ៦០០ ផលិតផល ចំណេញបាន ៤០០០$ (កៀកគោលដៅ)
  • របារបៃតង៖ លក់បាន ៨០០ ផលិតផល ចំណេញ ៦០០០$ (រំលងបន្ទាត់គោលដៅពណ៌ខៀវ!)
វិសមីការ៖ \(10x - 2000 \ge 5000\)

\(\Rightarrow 10x \ge 5000 + 2000\)

\(\Rightarrow 10x \ge 7000 \Rightarrow x \ge 700\)

សន្និដ្ឋាន៖ ក្រុមហ៊ុនត្រូវលក់យ៉ាងតិច ៧០០ ផលិតផល។

អូសបង្វិល (4D Animate)

រោងចក្រផលិត និងក្រាហ្វិកប្រាក់ចំណេញជាក់ស្តែង

លំហាត់សុខាភិបាល (ការគណនាជីវជាតិប្រចាំថ្ងៃ)

អ្នកជំងឺម្នាក់ត្រូវទទួលបានជាតិកាល់ស្យូម យ៉ាងតិច \(800mg\) ក្នុងមួយថ្ងៃ។ បើគាត់ទទួលបានពីអាហារផ្សេងៗចំនួន \(300mg\) រួចហើយ ហើយទឹកដោះគោមួយកែវអាចផ្តល់ជាតិកាល់ស្យូមបាន \(250mg\)។ តើគាត់ត្រូវផឹកទឹកដោះគោបន្ថែមយ៉ាងតិចប៉ុន្មានកែវទៀត?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនកែវទឹកដោះគោដែលត្រូវផឹក (\(x > 0\))
  • ជាតិកាល់ស្យូមសរុប = \(250x + 300\)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីការផឹកទឹកដោះគោបន្ថែមម្តងមួយកែវ។ កម្រិតកាល់ស្យូមក្នុងរាងកាយកើនឡើងពី 300mg បន្តបន្ទាប់ រហូតដល់ឆ្លងកាត់បន្ទាត់គោលដៅ 800mg ទើបលោតសញ្ញាជោគជ័យពណ៌បៃតង។
វិសមីការ៖ \(250x + 300 \ge 800\)

\(\Rightarrow 250x \ge 800 - 300\)

\(\Rightarrow 250x \ge 500 \Rightarrow x \ge 2\)

សន្និដ្ឋាន៖ អ្នកជំងឺត្រូវផឹកទឹកដោះគោបន្ថែមយ៉ាងតិច ២ កែវ។

អូសបង្វិល (4D Animate)

ការបំពេញកម្រិតកាល់ស្យូមក្នុងរាងកាយ

លំហាត់បច្ចេកវិទ្យា (ការជ្រើសរើសគម្រោងអ៊ីនធឺណិត)

គម្រោងអ៊ីនធឺណិត A តម្រូវឲ្យបង់ \(5\$\) ថេរប្រចាំខែ និងបង់បន្ថែម \(1\$\) ក្នុងមួយ GB (Gigabyte)। ចំណែកគម្រោង B បង់ \(15\$\) ប្រើមិនកំណត់។ តើត្រូវប្រើទិន្នន័យលើសពីប៉ុន្មាន GB ទើបការជ្រើសរើសគម្រោង B ចំណេញជាង?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនទិន្នន័យដែលបានប្រើប្រាស់ (គិតជា GB) (\(x > 0\))
  • ការចំណាយគម្រោង A = \(5 + 1x\) (ដុល្លារ)
  • ការចំណាយគម្រោង B = \(15\) (ដុល្លារ ថេរជានិច្ច)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីការកើនឡើងនៃទិន្នន័យ (Data) តាមពេលវេលាជាក់ស្តែង។ ផ្ទាំងកុងទ័រនឹងគណនាតម្លៃនៃគម្រោងទាំងពីរប្រណាំងគ្នា ដោយប្តូរពណ៌បៃតងលើគម្រោងណាដែលថោកជាង (ចំណេញជាង)។
វិសមីការ៖ \(15 < 5 + x\) ឬ \(5 + x > 15\)

\(\Rightarrow x > 15 - 5\)

\(\Rightarrow x > 10\)

សន្និដ្ឋាន៖ ត្រូវប្រើទិន្នន័យលើសពី ១០ GB ទើបគម្រោង B ចំណេញជាង។

អូសបង្វិល (4D Data Stream)

ការបញ្ជូនទិន្នន័យ និងការគណនាតម្លៃជាក់ស្តែង

លំហាត់បរិស្ថាន (ការកម្រិតការបញ្ចេញឧស្ម័ន CO2)

ទីក្រុងមួយចង់ដាក់កំហិតការបញ្ចេញឧស្ម័នពុល CO2 ឱ្យនៅ ក្រោម \(50\) តោន ក្នុងមួយខែ। រោងចក្រមួយបញ្ចេញឧស្ម័ននេះ \(2\) តោន/ថ្ងៃ। បើសិនជានៅដើមខែ រោងចក្រនោះបានបញ្ចេញអស់ \(10\) តោន រួចទៅហើយ តើអាចដំណើរការបានច្រើនបំផុតប៉ុន្មានថ្ងៃទៀត ទើបមិនលើសកម្រិតកំណត់?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនថ្ងៃដែលអាចដំណើរការបន្ត (\(x > 0\))
  • បរិមាណបញ្ចេញបន្ថែមក្នុង \(x\) ថ្ងៃ = \(2x\)
  • បរិមាណឧស្ម័នសរុប = \(2x + 10\)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីការកើនឡើងនៃឧស្ម័ន CO2 តាមពេលវេលាជាក់ស្តែង។ ពេលចំនួនថ្ងៃកើនឡើង បរិមាណផ្សែងនឹងកើនឡើង ហើយផ្ទៃមេឃនឹងប្រែជាងងឹតអាប់អួរ រហូតដល់ជាន់បន្ទាត់ក្រហម (៥០ តោន)។
វិសមីការ៖ \(2x + 10 \le 50\)

\(\Rightarrow 2x \le 50 - 10\)

\(\Rightarrow 2x \le 40 \Rightarrow x \le 20\)

សន្និដ្ឋាន៖ រោងចក្រអាចដំណើរការបានច្រើនបំផុត ២០ ថ្ងៃទៀតប៉ុណ្ណោះ។

អូសបង្វិល (4D Simulation)

រោងចក្របញ្ចេញផ្សែងប៉ះពាល់បរិស្ថានតាមពេលវេលា

លំហាត់ដឹកជញ្ជូន (ការគណនាទម្ងន់ផ្ទុកអតិបរមា)

រថយន្តដឹកទំនិញមួយគ្រឿងត្រូវបានអនុញ្ញាតឱ្យផ្ទុកទម្ងន់សរុប (រួមទាំងតួឡាន) អតិបរមាត្រឹម \(5000kg\)។ បើរថយន្តទទេមានទម្ងន់ \(2000kg\) ហើយទំនិញនីមួយៗត្រូវបានច្រកក្នុងកេសស្តង់ដារដែលមានទម្ងន់ \(50kg\) ក្នុងមួយកេស។ តើគេអាចផ្ទុកទំនិញបានច្រើនបំផុតប៉ុន្មានកេស ដើម្បីធានាសុវត្ថិភាពនិងមិនល្មើសច្បាប់ចរាចរណ៍?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនកេសទំនិញដែលត្រូវផ្ទុកលើឡាន (\(x \ge 0\))
  • ទម្ងន់ទំនិញសុទ្ធសរុប = \(50x\)
  • ទម្ងន់ឡាននិងទំនិញសរុប = ទម្ងន់ឡានទទេ + ទម្ងន់ទំនិញ = \(2000 + 50x\)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីការផ្ទុកទំនិញចូលឡានម្តងមួយកេសៗ ធ្វើឱ្យទម្ងន់កើនឡើងបន្តិចម្តងៗ និងយឺតឡានស្រុតចុះ រហូតដល់ពេញកម្រិត 5000kg ទើបបញ្ឈប់។
វិសមីការ៖ \(50x + 2000 \le 5000\)

\(\Rightarrow 50x \le 5000 - 2000\)

\(\Rightarrow 50x \le 3000 \Rightarrow x \le \frac{3000}{50}\)

\(\Rightarrow x \le 60\)

សន្និដ្ឋាន៖ រថយន្តអាចផ្ទុកទំនិញបានអតិបរមាចំនួន ៦០ កេស។

អូសបង្វិលមើលការផ្ទុក (4D Animate)

រថយន្តកំពុងបើកបរ និងផ្ទុកទំនិញជាក់ស្តែង

លំហាត់ថាមពល (ការគណនាចំនួនផ្ទាំងសូឡា)

គ្រួសារមួយត្រូវការប្រើប្រាស់ថាមពលអគ្គិសនី យ៉ាងតិច \(3000 Wh\) ក្នុងមួយថ្ងៃ। ពួកគាត់មានកង្ហារខ្យល់មួយដែលផលិតថាមពលបាន \(500 Wh\) ក្នុងមួយថ្ងៃរួចហើយ। បើផ្ទាំងសូឡាមួយផ្ទាំងអាចផលិតថាមពលបាន \(250 Wh\) ក្នុងមួយថ្ងៃ តើពួកគាត់ត្រូវទិញផ្ទាំងសូឡាយ៉ាងតិចប៉ុន្មានផ្ទាំង ទើបគ្រប់គ្រាន់សម្រាប់ការប្រើប្រាស់?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនផ្ទាំងសូឡាដែលត្រូវទិញ (\(x > 0\))
  • ថាមពលទទួលបានពីផ្ទាំងសូឡា = \(250x\)
  • ថាមពលសរុប (សូឡា + កង្ហារខ្យល់) = \(250x + 500\)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីបម្រែបម្រួលពេលវេលា (Day/Night Cycle)។ ថាមពលខ្យល់កើនឡើងជាប់រហូត ចំណែកឯផ្ទាំងសូឡាទាំង១០ ផលិតថាមពលបានតែពេលថ្ងៃ (មានពន្លឺព្រះអាទិត្យ) ដើម្បីបំពេញគោលដៅ 3000Wh នៅចុងបញ្ចប់នៃថ្ងៃ។
វិសមីការ៖ \(250x + 500 \ge 3000\)

\(\Rightarrow 250x \ge 3000 - 500\)

\(\Rightarrow 250x \ge 2500 \Rightarrow x \ge 10\)

សន្និដ្ឋាន៖ គ្រួសារនេះត្រូវទិញផ្ទាំងសូឡាយ៉ាងតិច ១០ ផ្ទាំង។

អូសបង្វិល (4D Animate)

ផ្ទះបំពាក់ផ្ទាំងសូឡា១០ និងការគណនាថាមពលជាក់ស្តែង

លំហាត់យោធា (ការគណនាបន្ទុកប្រតិបត្តិការ)

ឧទ្ធម្ភាគចក្រយោធាមួយគ្រឿងអាចហោះហើរដោយផ្ទុកទម្ងន់បានអតិបរមា \(2500kg\)। បើពីឡុតនិងសហសេវិកមានទម្ងន់សរុប \(160kg\) ហើយកេសស្បៀង ឬគ្រាប់រំសេវមួយកេសមានទម្ងន់ \(80kg\)។ តើឧទ្ធម្ភាគចក្រនេះអាចដឹកទំនិញបានច្រើនបំផុតប៉ុន្មានកេស ទើបធានាបាននូវសុវត្ថិភាពហោះហើរ?

បកស្រាយលម្អិត និងទំនាក់ទំនងជាមួយគំរូ 4D៖

  • តាង \(x\) ជាចំនួនកេសដែលត្រូវដឹក (\(x \ge 0\), គិតជាចំនួនគត់)
  • ទម្ងន់ទំនិញសរុប = \(80x\)
  • ទម្ងន់សរុប (ទំនិញ + ពីឡុត) = \(80x + 160\)
  • គំនូរជីវចល 4D ខាងស្តាំ៖ បង្ហាញពីឧទ្ធម្ភាគចក្រកំពុងស្ទូចទំនិញឡើង។ ចំនួនកេសកើនឡើងជាលំដាប់ ធ្វើឲ្យទម្ងន់សរុបកើនឡើង។ បើទម្ងន់លើស ២៥០០kg ឧទ្ធម្ភាគចក្រនឹងធ្លាក់ចុះ និងលោតសញ្ញាអាសន្ន!
វិសមីការ៖ \(80x + 160 \le 2500\)

\(\Rightarrow 80x \le 2500 - 160\)

\(\Rightarrow 80x \le 2340 \Rightarrow x \le 29.25\)
